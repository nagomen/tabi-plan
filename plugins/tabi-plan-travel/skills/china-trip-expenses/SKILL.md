# 香港・マカオ・金門旅行

このスキルは、この旅行だけに接続された Tabi Plan MCP を使う。

## 費用の扱い

1. まず `list_trip_expenses` を呼び、旅行内メンバーID、基準通貨、既存費用を確認する。
2. 内容、支払日、支払額、通貨、換算レート、支払者、負担者と負担額、支払方法を推測しない。不足があれば質問する。
3. 追加・訂正・削除の直前に、変更後の内容を短い日本語で利用者へ示し、確認を得る。
4. 外貨の換算レートは支払日ごとの確定値として扱う。既存費用のレートを現在値で上書きしない。
5. 複数件は、先に全件を編集可能な一覧として提示してから、一件ずつ保存結果を確認する。
6. 削除には `delete_trip_expense` を使う。物理削除ではなく、必要なら `restore_trip_expense` で戻す。

旅行IDや別旅行を入力として組み立てない。このプラグインの対象は香港・マカオ・金門旅行だけである。
